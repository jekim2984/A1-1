# 나만의 프롬프트 관리 프로그램 (Prompt Manager)

파이썬 기초 문법과 Git/GitHub 협업 워크플로우를 활용하여 구현한 콘솔 기반의 프롬프트 관리 시스템입니다.  
터미널 환경에서 다양한 프롬프트를 카테고리별로 체계적으로 분류하고, 즐겨찾기 및 조회수로 관리하며, JSON 파일 영속화 및 Markdown 내보내기 기능을 제공합니다.

---

## 🚀 실행 방법

1. **Python 버전 확인**: Python 3.10 이상 환경을 권장합니다.
   ```bash
   python3 --version
   ```
2. **프로그램 실행**:
   ```bash
   python3 prompt_manager.py
   ```

---

## 📌 기능 목록

### [기본 기능]
1. **프롬프트 추가**: 제목, 내용, 카테고리를 입력받아 신규 프롬프트를 등록합니다. (빈 값 방지 및 유효성 검사 적용)
2. **프롬프트 목록 조회**: 등록된 전체 프롬프트를 번호, 카테고리, 제목, 즐겨찾기(⭐) 여부와 함께 조회합니다.
3. **카테고리별 조회**: 원하는 카테고리를 선택하여 해당 그룹의 프롬프트만 필터링하여 확인합니다.
4. **프롬프트 검색**: 키워드를 입력하여 제목이나 내용에 검색어가 포함된 프롬프트를 검색합니다.
5. **프롬프트 상세 보기**: 프롬프트 번호를 입력해 전체 내용을 상세히 확인하며, 조회 시 조회수가 1회 증가합니다.
6. **즐겨찾기 관리**: 프롬프트의 즐겨찾기 상태를 간편하게 추가/해제(토글)합니다.
7. **즐겨찾기 목록**: 즐겨찾기로 등록된 프롬프트들만 모아서 조회합니다.
8. **프롬프트 수정**: 기존 프롬프트의 제목 및 내용을 수정합니다. (엔터 입력 시 기존 내용 유지)
9. **프롬프트 삭제**: 확인 절차(`y/n`)를 거쳐 프롬프트를 안전하게 삭제합니다.

### [보너스 기능]
10. **인기 프롬프트 Top 목록 (보너스 2)**: 프롬프트 상세 조회 시 누적된 조회수(`views`)를 기준으로 인기 프롬프트를 내림차순 정렬하여 보여줍니다.
11. **Markdown 파일로 내보내기 (보너스 1)**: 전체 프롬프트를 카테고리별 목차와 본문 형식의 깔끔한 마크다운 문서(`prompts_by_category.md`)로 내보냅니다.
* **데이터 영속화 (보너스 1)**: `prompts.json` 파일을 통해 프로그램 종료 후 재실행 시에도 모든 데이터(추가, 수정, 삭제, 즐겨찾기, 조회수)가 유지됩니다.

## 📂 등록된 프롬프트 카테고리

- **텍스트 생성**: 블로그 글, 이메일, 문서 초안 등 텍스트 작성을 돕는 프롬프트
- **이미지 생성**: Midjourney, DALL-E 등 고품질 이미지 생성을 위한 프롬프트
- **영상 생성**: 숏폼, 릴스 등 영상 기획 및 스크립트 작성 프롬프트
- **페르소나**: AI에게 특정 직업, 전문성, 성격을 부여하는 역할 기반 프롬프트
- **자동화**: 업무 효율 향상, 데이터 요약 및 정리 자동화 프롬프트
- **기타**: 다양한 범용 및 실험적 프롬프트

## 🛠️ 기술 스택 및 개발 환경

- **언어**: Python 3.12 (기본 내장 모듈 `os`, `json`만 활용)
- **버전 관리**: Git, GitHub
- **주요 문법**: 자료구조(List, Dict), 제어문(if, while, for), 함수 분리, 파일 입출력(File I/O), 예외 처리
