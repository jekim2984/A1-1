# 나만의 프롬프트 관리 프로그램 (Prompt Manager)

파이썬 기초 문법과 Git/GitHub을 활용하여 구현한 콘솔 기반의 프롬프트 관리 시스템입니다.
터미널 환경에서 다양한 프롬프트를 카테고리별로 분류하고, 즐겨찾기로 관리하며, 키워드로 쉽게 검색할 수 있도록 돕습니다.

## 🚀 실행 방법

1. 파이썬이 설치되어 있는지 확인합니다. (Python 3.10 이상 권장)
2. 터미널(또는 명령 프롬프트)을 열고 소스 코드가 있는 디렉터리로 이동합니다.
3. 아래 명령어를 입력하여 프로그램을 실행합니다.
   ```bash
   python3 prompt_manager.py
   ```

## 📌 기능 목록

- **프롬프트 추가**: 새로운 프롬프트의 제목, 내용, 카테고리를 입력하여 등록할 수 있습니다.
- **프롬프트 목록 조회**: 등록된 전체 프롬프트를 번호, 카테고리, 제목, 즐겨찾기 여부(⭐)와 함께 한눈에 확인합니다.
- **카테고리별 조회**: 원하는 카테고리를 선택하여 해당 그룹에 속한 프롬프트만 필터링하여 봅니다.
- **프롬프트 검색**: 키워드를 입력하면 제목 또는 내용에 해당 단어가 포함된 프롬프트를 찾아줍니다.
- **프롬프트 상세 보기**: 목록에서 번호를 선택해 프롬프트의 전체 내용을 상세하게 확인합니다.
- **즐겨찾기 추가/해제**: 자주 사용하는 프롬프트를 즐겨찾기에 등록하거나 해제할 수 있습니다.
- **즐겨찾기 목록**: 즐겨찾기로 지정한 프롬프트들만 따로 모아서 조회합니다.
- **프롬프트 수정/삭제 (보너스)**: 등록된 프롬프트의 내용을 수정하거나 삭제할 수 있습니다.

## 📂 등록된 프롬프트 카테고리

현재 시스템에서 관리할 수 있는 프롬프트 카테고리는 다음과 같습니다.

- **텍스트 생성**: 블로그 글, 이메일, 문서 초안 등 텍스트 작성을 지시하는 프롬프트
- **이미지 생성**: Midjourney, DALL-E 등 이미지 생성 AI를 위한 프롬프트
- **영상 생성**: 숏폼, 릴스 등 영상 기획 및 스크립트 작성을 위한 프롬프트
- **페르소나**: AI에게 특정 직업, 성격, 역할을 부여하는 프롬프트
- **자동화**: 업무 효율 향상, 데이터 요약 등 자동화 작업을 위한 프롬프트
- **기타**: 위 분류에 해당하지 않는 다양한 범용 프롬프트
